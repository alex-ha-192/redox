# Redox

An implementation of [the SIMPLE programming language](https://github.com/alex-ha-192/simplelang), written in Rust.

> [!CAUTION]
> As this is a work-in-progress, please don't rely on this, or the SIMPLE language as it currently exists, for anything important/anything long-term. Neither are stable, and I have no plans currently to indefinitely support either.

This project was started by [Alex Hegedus-Adkin](https://www.github.com/alex-ha-192), the creator of the SIMPLE programming language specification, but this implementation is not to be taken as a reference implementation of the language; all ambiguities relating to SIMPLE should be handled by suitably modifying the language spec.
